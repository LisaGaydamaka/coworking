# План выделения главных признаков для сокращённого eNRI

## 1. Цель

Задача состоит из двух последовательных этапов:

1. получить устойчивый полный eNRI по 30 модельным признакам;
2. выделить минимальный устойчивый набор главных признаков и заново обучить eNRI только по ним.

Сокращённый eNRI не получается простым удалением малых коэффициентов из полной модели. После выбора набора признаков веса обязательно переоцениваются заново в том же constrained-QP.

Главный принцип:

\[
\boxed{
\text{главный признак}
\neq
\text{большой коэффициент в одной модели}
}
\]

а

\[
\boxed{
\text{главный признак}
=
\text{часто выбирается}
+
\text{стабилен по знаку}
+
\text{не заменяется полностью коррелированными соседями}
+
\text{его удаление ухудшает модель}
+
\text{он нужен в хорошем reduced eNRI}
}
\]

## 2. Базовая модель для feature selection

В качестве исходной точки используем первую модель:

\[
\beta=0.1,\qquad
\lambda_2=0.1,\qquad
C=0.1,\qquad
\rho=0.1.
\]

Для этапа feature selection используем полный исходный набор из 10 направленных условий.

### 2.1. Мягкие равенства

\[
PBS^0\approx LPS^0
\]

\[
PBS^0\approx run^0
\]

\[
PBS^0\approx MCC^0
\]

\[
LPS^{16}\approx run^{16}
\]

\[
LPS^{16}\approx MCC^{16}
\]

### 2.2. Направленные условия

\[
PBS^{16}>LPS^{16}
\]

\[
PBS^{24}>LPS^{24}
\]

\[
run^{24}>LPS^{24}
\]

\[
MCC^{24}>LPS^{24}
\]

\[
PBS^0>PBS^{16}
\]

\[
LPS^0>LPS^{16}
\]

\[
run^0>run^{16}
\]

\[
MCC^0>MCC^{16}
\]

\[
PBS^{16}>PBS^{24}
\]

\[
LPS^{16}>LPS^{24}.
\]

Каждое направленное условие реализуется как

\[
A-B\ge\rho-\eta,\qquad \eta\ge0.
\]

Условия

\[
run^{24}>LPS^{24},
\qquad
MCC^{24}>LPS^{24}
\]

снова являются частью конструкции модели. Поэтому их выполнение нельзя интерпретировать как независимое доказательство эффективности run или MCC.

## 3. Что не меняем во всём pipeline

На всех этапах сохраняются:

- анализ на уровне mouse_id;
- все состояния одной мыши находятся только в train или только в validation;
- train-only preprocessing внутри CV;
- train-only baseline scaling;
- train-only censor maxima;
- train-only fit статистического imputer;
- фиксированная группа мыши;
- death \(\rightarrow eNRI=0\);
- positivity для живых:

\[
eNRI\ge0.001;
\]

- нормировка:

\[
PBS^0=1;
\]

- 30 MODEL_FEATURES как полный исходный набор;
- 5 детерминированных NOR-признаков не получают отдельных весов;
- полный QC;
- сравнение весов между folds через raw-scale slopes:

\[
\gamma_j=\frac{w_j}{s_j}.
\]

Прямое сравнение стандартизованных \(w_j\) между folds не используется как основная оценка стабильности.

## 4. Почему нельзя выбирать признаки по одному \(|w_j|\)

При \(n=54\) и \(p=30\):

- один сигнал может распределяться между несколькими коррелированными признаками;
- знак коэффициента может меняться между folds;
- большой коэффициент может появляться из-за конкретного состава маленькой выборки;
- ridge-регуляризация стабилизирует модель, но обычно не зануляет ненужные признаки.

Поэтому величина \(|w_j|\) используется только как дополнительная характеристика, а не как основной selector.

# Этап A. Анализ коррелированных блоков

## A1. Корреляции

Для каждой пары признаков отдельно считаются Spearman-корреляции:

\[
r_s^0,\qquad
r_s^{16},\qquad
r_s^{24},
\]

только по живым мышам соответствующего состояния.

Не объединять все состояния в одну общую корреляционную матрицу как независимые наблюдения.

## A2. Определение устойчивой сильной связи

Пара признаков относится к одному сильному корреляционному блоку, если:

1. минимум в двух из трёх состояний выполняется

\[
|r_s|\ge0.8;
\]

2. знак корреляции в этих состояниях совпадает.

Пример:

\[
r_s^0=0.91,\quad
r_s^{16}=0.86,\quad
r_s^{24}=0.78
\]

считается устойчивой сильной связью.

## A3. Что делать с блоками

Коррелированные признаки автоматически не удаляются.

Блоки используются для:

- интерпретации stability selection;
- оценки взаимозаменяемости признаков;
- block ablation;
- объяснения случаев, когда конкретный признак выбирается нестабильно, но сам информационный блок выбирается почти всегда.

Если correlation blocks влияют на выбор признака внутри nested CV, они вычисляются только внутри outer-train.

# Этап B. Sparse constrained eNRI

## B1. Целевая функция

К текущей целевой функции добавляется \(L_1\)-штраф:

\[
L_{\text{current}}
+
\lambda_1\|w\|_1
+
\lambda_2\|w\|_2^2.
\]

Используется constrained Elastic Net.

На первом sparse-проходе фиксируем:

\[
\beta=0.1,\qquad
\lambda_2=0.1,\qquad
C=0.1,\qquad
\rho=0.1,
\]

и варьируем только

\[
\lambda_1.
\]

## B2. Сетка \(\lambda_1\)

Использовать заранее фиксированную сетку:

\[
\lambda_1\in
\{
0,\,
10^{-5},\,
3\cdot10^{-5},\,
10^{-4},\,
3\cdot10^{-4},\,
10^{-3},\,
3\cdot10^{-3},\,
10^{-2},\,
3\cdot10^{-2},\,
10^{-1},\,
3\cdot10^{-1}
\}.
\]

Если при \(\lambda_1=0.3\) модель всё ещё остаётся практически полной, сетка автоматически расширяется:

\[
1,\ 3.
\]

Расширение выполняется по этому заранее заданному правилу, а не вручную после просмотра результатов.

## B3. Что считать выбранным признаком

Признак считается active, если

\[
|w_j|>10^{-6}.
\]

Порог \(10^{-6}\) используется только как numerical zero threshold.

## B4. Что сохранять для каждого \(\lambda_1\)

- число active features;
- список active features;
- \(V_{pos}\);
- \(V_{sign}\);
- \(V_{margin}\);
- \(V_{eq}\);
- \(V_{var}\);
- \(V_w\);
- slack sum;
- slack max;
- solver status.

# Этап C. Stability selection

## C1. Resampling

Для оценки стабильности выбора признаков использовать отдельный mouse-level resampling.

Цель:

\[
\ge100
\]

валидных stratified resamples; предпочтительно 200, если вычислительно это не создаёт проблем.

В каждом resample брать примерно 80% мышей в train с сохранением представительства групп:

\[
PBS,\ LPS,\ run,\ MCC.
\]

Все состояния одной мыши всегда остаются вместе.

Невалидный resample отбрасывается, если после preprocessing невозможно корректно построить необходимые состояния или решить QP.

## C2. Полный train-only pipeline

В каждом resample заново выполняются:

1. deterministic preprocessing;
2. censor maxima;
3. baseline scaling;
4. statistical imputation;
5. построение состояний;
6. sparse constrained QP.

Никакие статистики полного датасета не используются.

## C3. Частота выбора

Для каждого признака:

\[
\pi_j=
\frac{
\#\{\text{валидные resamples, где } |w_j|>10^{-6}\}
}{
\#\{\text{валидные resamples}\}
}.
\]

## C4. Стабильность знака

Знак оценивается только среди resamples, где признак active:

\[
s_j=
\max
\left[
P(w_j>0\mid selected),
P(w_j<0\mid selected)
\right].
\]

## C5. Категории

### Core feature

\[
\pi_j\ge0.8
\]

и

\[
s_j\ge0.9.
\]

### Candidate feature

\[
0.6\le\pi_j<0.8
\]

и

\[
s_j\ge0.8.
\]

Признаки ниже этих порогов не удаляются автоматически, если они входят в устойчивый коррелированный блок.

## C6. Что сохранять

Для каждого признака:

- \(\pi_j\);
- positive sign frequency;
- negative sign frequency;
- \(s_j\);
- median \(\gamma_j\);
- q10 \(\gamma_j\);
- q90 \(\gamma_j\);
- median \(|\gamma_j|\).

# Этап D. Block stability

Для каждого correlation block считать вероятность выбора хотя бы одного его представителя:

\[
P(\text{любой признак блока selected}).
\]

Это нужно для случаев, когда два или несколько сильно коррелированных признаков заменяют друг друга.

Пример:

\[
\pi_A=0.50,\qquad
\pi_B=0.50,
\]

но

\[
P(A\lor B)=0.95.
\]

В таком случае блок считается устойчивым, хотя конкретный представитель блока неустойчив.

# Этап E. Ablation analysis

## E1. Feature ablation

Для каждого core/candidate признака:

1. удалить этот признак;
2. заново обучить модель;
3. использовать те же CV splits, что и в reference-модели;
4. сравнить paired out-of-sample metrics.

Считать:

\[
\Delta V_{pos},
\quad
\Delta V_{sign},
\quad
\Delta V_{margin},
\quad
\Delta V_{eq},
\quad
\Delta V_{var}.
\]

## E2. Block ablation

Для каждого сильного correlation block:

1. удалить весь блок;
2. заново обучить модель;
3. оценить те же paired изменения.

Это позволяет отличить:

- реально важный информационный блок;
- конкретный признак, который полностью заменяется соседом.

## E3. Правило интерпретации

Не использовать произвольное правило типа «ухудшение на 5%».

Основная оценка — paired distribution изменений на одних и тех же mouse-level splits.

Признак/блок считается действительно важным, если его удаление систематически ухудшает более приоритетные validation-метрики и это ухудшение заметно относительно естественной межsplit-вариабельности reference-модели.

# Этап F. Формирование наборов размера \(k\)

## F1. Ranking признаков

Признаки ранжируются последовательно по:

1. selection frequency \(\pi_j\);
2. sign stability \(s_j\);
3. ablation importance;
4. median \(|\gamma_j|\).

Correlation blocks учитываются отдельно, чтобы не наказывать взаимозаменяемые признаки дважды.

## F2. Наборы кандидатов

Построить:

\[
S_3,S_4,\ldots,S_{15}.
\]

\(S_k\) содержит \(k\) наиболее устойчивых кандидатов по заранее определённому ranking.

## F3. Обязательный refit

Для каждого \(S_k\):

1. оставить только эти \(k\) признаков;
2. заново выполнить preprocessing;
3. заново обучить constrained QP;
4. получить новые веса.

Старые веса полной модели не переносятся.

# Этап G. Выбор минимального достаточного \(k\)

Для каждого \(k\) оценить out-of-sample:

\[
V_{pos},
\quad
V_{sign},
\quad
V_{margin},
\quad
V_{eq},
\quad
V_{var},
\quad
V_w.
\]

Использовать правило smallest-within-one-SE.

Приоритет метрик сохраняется:

\[
V_{pos}
\rightarrow
V_{sign}
\rightarrow
V_{margin}
\rightarrow
V_{eq}
\rightarrow
V_{var}.
\]

Для каждой следующей метрики оставить модели, которые находятся в пределах одного standard error от лучшей модели по этой метрике.

После последовательного применения правил выбрать:

\[
\boxed{\min k}
\]

среди оставшихся моделей.

Цель — выбрать самую маленькую модель, качество которой практически не отличается от лучшей более сложной модели.

# Этап H. Nested mouse-level validation

## H1. Зачем

Окончательная оценка reduced eNRI должна выполняться на данных, которые не участвовали ни в выборе признаков, ни в выборе \(\lambda_1\), ни в выборе \(k\).

## H2. Outer splits

Использовать примерно 20–30 валидных repeated stratified mouse-level outer splits.

Все состояния одной мыши находятся только в одной части split.

Outer-validation никогда не используется для:

- correlation blocks;
- выбора \(\lambda_1\);
- stability selection;
- ranking;
- выбора \(k\);
- выбора subset.

## H3. Внутри каждого outer-train

Полностью заново выполнить:

\[
correlations
\rightarrow
\lambda_1\ selection
\rightarrow
stability\ selection
\rightarrow
block\ analysis
\rightarrow
ablation
\rightarrow
ranking
\rightarrow
k\ selection
\rightarrow
subset.
\]

После этого на всём outer-train заново обучить reduced constrained QP.

## H4. Outer validation

На outer-validation только вычислить:

\[
V_{pos},
V_{sign},
V_{margin},
V_{eq},
V_{var},
V_w.
\]

Также сохранить:

- выбранный \(k\);
- выбранный subset;
- частоту повторного выбора каждого признака;
- частоту повторного выбора одного и того же subset;
- групповые средние eNRI;
- slack diagnostics.

# Этап I. Reduced preprocessing

Основная reduced-модель должна реально требовать только выбранные признаки.

Если финальный subset:

\[
S=\{j_1,\ldots,j_k\},
\]

то primary reduced pipeline:

- хранит только эти признаки;
- обучает scaling только по ним;
- обучает imputer только по ним;
- вычисляет eNRI только по ним.

Не использовать остальные 30 признаков как скрытые predictors для основной reduced-импутации.

Дополнительно разрешён sensitivity-анализ:

\[
\text{selected features}
+
\text{all-30-assisted imputation},
\]

но он не является основной reduced-моделью.

# Этап J. Longitudinal sensitivity

Longitudinal analysis используется только как sensitivity и интерпретация, а не как selector.

Для мышей, живых в обеих соответствующих точках, считать:

\[
\Delta x_i^{0\to16}
=
x_i^{16}-x_i^0,
\]

\[
\Delta x_i^{16\to24}
=
x_i^{24}-x_i^{16}.
\]

Особенно анализировать интервал:

\[
16\rightarrow24,
\]

поскольку именно после состояния 16 начинаются различающие воздействия run/MCC.

Для умерших мышей feature-delta после смерти не вычислять и не заменять смерть нулевым значением признака.

При необходимости mixed-effects модели использовать только как дополнительный sensitivity analysis.

Отсутствие статистической значимости longitudinal signal само по себе не является основанием для удаления признака из-за низкой мощности выборки.

# Этап K. Финальный refit reduced eNRI

После завершения nested validation и выбора окончательного subset:

1. оставить только выбранные признаки;
2. выполнить full-data preprocessing только для них;
3. пересчитать baseline scaling;
4. пересчитать \(\overline{x}_{PBS^0}\);
5. построить 12 состояний;
6. решить constrained QP со всеми 5 равенствами и 10 направленными условиями;
7. получить новые reduced-веса;
8. сохранить финальную формулу.

Формула:

\[
eNRI_{\text{reduced}}
=
1+
\sum_{j\in S}
w_j^{\text{reduced}}
\left(
x_j-\overline{x}_{PBS^0,j}
\right).
\]

# Этап L. Сравнение full и reduced eNRI

Для reduced eNRI повторить полный robustness-анализ уровня Stage 8.

Сравнивать:

- positivity;
- equality errors;
- order errors;
- slack sum;
- slack max;
- индивидуальные eNRI;
- Spearman rank correlation;
- group-rank Spearman;
- group mean differences;
- complete-case sensitivity;
- \(\rho\)-sensitivity;
- imputation sensitivity;
- longitudinal sensitivity.

Для сравнения направлений весов reduced \(\gamma\)-вектор дополняется нулями до исходных 30 координат, после чего вычисляется cosine similarity с full-model \(\gamma\).

# Этап M. Критерии итогового признания признака главным

Признак считается главным не по одному показателю, а по совокупности:

1. высокая selection frequency;
2. стабильный знак;
3. устойчивый raw-scale slope;
4. принадлежность к устойчивому информационному блоку или самостоятельная устойчивость;
5. ухудшение out-of-sample качества при feature/block ablation;
6. повторный выбор во внешних nested-CV итерациях;
7. присутствие в минимальном достаточном reduced subset;
8. разумная longitudinal интерпретируемость.

# Этап N. Методы, которые не использовать как основной selector

Не использовать как основной способ отбора:

- top-\(|w_j|\) из одной full-data модели;
- stepwise regression;
- выбор по отдельным p-value;
- Random Forest feature importance;
- XGBoost feature importance;
- SHAP;
- PCA как финальный feature selector;
- чистый LASSO без \(L_2\)-части при сильной корреляции признаков.

Эти методы могут использоваться только как дополнительный exploratory/sensitivity analysis, если понадобится.

## 7. Критическое правило остановки

Нельзя объявлять reduced eNRI успешным только потому, что он использует мало признаков.

Сокращённая модель принимается только если:

1. её out-of-sample качество находится в пределах выбранного one-SE критерия относительно лучшей модели;
2. она не демонстрирует существенно худшую устойчивость, чем полный eNRI;
3. выбранные признаки воспроизводимо появляются при изменении состава мышей;
4. модель корректно работает, используя только выбранный набор признаков.

Если устойчивого малого subset не существует, результатом анализа должно быть именно это, а не принудительный выбор нескольких признаков.
