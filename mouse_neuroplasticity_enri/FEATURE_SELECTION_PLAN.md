# План выделения главных признаков для сокращённого eNRI

## 1. Цель

Текущая задача состоит из двух последовательных этапов:

1. построить устойчивый полный eNRI по 30 модельным признакам;
2. выделить минимальный набор главных признаков и заново обучить eNRI только по ним.

Сокращённый eNRI не должен получаться простым удалением малых коэффициентов из полной модели. После выбора набора признаков веса должны быть переоценены заново в том же constrained-QP.

## 3. Ограничения, которые не меняем

На всех этапах сохраняются:

- mouse-level repeated stratified CV;
- все состояния одной мыши только в train или только в validation;
- train-only preprocessing внутри CV;
- train-only baseline scaling;
- train-only IterativeImputer;
- train-only censor maxima;
- 30 MODEL_FEATURES;
- 5 детерминированных NOR-признаков без отдельных eNRI-весов;
- death (ightarrow eNRI=0);

- нормировка (PBS^0=1);
- fixed groups;
- полный QC;
- сравнение весов между folds через raw-scale slopes

[

]

а не напрямую через стандартизованные (w_j).

## 4. Почему нельзя выбирать признаки просто по (|w_j|)

Большой коэффициент в одной полной модели не означает, что признак действительно главный.

При (n=54) и 30 коррелированных признаках:

- один и тот же сигнал может распределяться между несколькими признаками;
- знак коэффициента может меняться между CV-folds;
- большой вес может быть следствием конкретного состава маленькой выборки;
- ridge-регуляризация стабилизирует веса, но обычно не делает их нулевыми.

Поэтому главный признак должен быть важен не только по величине веса, но и по устойчивости выбора, знака и влиянию на out-of-sample качество.

## 5. Этап A. Анализ коррелированных блоков

Перед sparse selection построить:

1. корреляционную матрицу 30 признаков;
2. иерархическую кластеризацию признаков;
3. список сильно зависимых блоков;
4. отдельную проверку семейств:
   - OFT;
   - NOR1;
   - NOR2;
   - rotarod;
   - rear;
   - Weight.

Особое внимание уделить комбинациям вида:

- mean / max / sum;
- переменным, описывающим один и тот же поведенческий процесс;
- почти линейно зависимым признакам.

Коррелированные признаки не удалять автоматически. Их необходимо рассматривать как конкурирующие представители одного информационного блока.

## 6. Этап B. Sparse constrained eNRI

К текущей целевой функции добавить (L_1)-штраф:

[
L_{	ext{current}}
+
lambda_1|w|_1
+
lambda_2|w|_2^2.
]

То есть использовать constrained Elastic Net.

На первом sparse-проходе зафиксировать:

[
eta=0.1,qquad
lambda_2=0.1,qquad
C=0.1,qquad
ho=0.1,
]

и варьировать только новый параметр sparsity:

[
lambda_1.
]

Не оптимизировать сразу большое количество новых гиперпараметров, чтобы не усиливать overfitting на маленьком датасете.

Для каждого (lambda_1) сохранять:

- число ненулевых весов;
- (V_{pos});
- (V_{sign});
- (V_{margin});
- (V_{eq});
- (V_{var});
- (V_w);
- slack sum;
- slack max;
- набор выбранных признаков.

## 7. Этап C. Stability selection

Для каждого принятого mouse-level CV split заново:

1. выполнить preprocessing только по train;
2. решить sparse constrained QP;
3. записать, какие признаки выбраны;
4. сохранить raw-scale slopes (gamma_j).

Для каждого признака считать:

[
P_j=P(w_j
e0),
]

то есть частоту выбора.

Также считать:

- positive sign frequency;
- negative sign frequency;
- sign agreement с full-data моделью;
- median (gamma_j);
- q10 и q90 (gamma_j);
- median (|gamma_j|).

Кандидат в главный признак должен:

1. часто выбираться;
2. сохранять знак;
3. иметь ненулевую величину эффекта;
4. не быть полностью заменяемым другим признаком того же коррелированного блока.

## 8. Этап D. Ablation analysis

Для каждого перспективного признака:

1. удалить его;
2. полностью переобучить модель;
3. повторно оценить validation-метрики.

Смотреть изменение:

[
Delta V_{pos},
Delta V_{sign},
Delta V_{margin},
Delta V_{eq},
Delta V_{var}.
]

Если удаление признака почти ничего не меняет, признак не является обязательным.

Для коррелированных признаков выполнять также block ablation:

- удалить не один признак, а весь коррелированный блок;
- проверить, насколько сильно ухудшается модель.

Это позволяет отличить:

- реально важный информационный блок;
- конкретный признак, который просто можно заменить соседним коррелированным признаком.

## 9. Этап E. Поиск минимального достаточного набора

Не задавать заранее фиксированное число главных признаков.

Проверить модели с различным количеством выбранных признаков:

[
k=3,4,ldots,15.
]

Для каждого (k) оценивать out-of-sample качество.

Нужно выбрать минимальный (k), после которого дальнейшее добавление признаков уже практически не улучшает:

[
V_{pos},
V_{sign},
V_{margin},
V_{eq},
V_{var}.
]

Главная цель — не максимальная сложность модели, а минимальный стабильный набор, сохраняющий качество полного eNRI.

## 10. Этап F. Nested mouse-level CV

Окончательная оценка reduced eNRI должна выполняться без selection bias.

Использовать nested CV:

### Внутренний цикл

На train части:

- preprocessing;
- подбор sparsity (lambda_1);
- stability selection;
- выбор признаков;
- переоценка весов.

### Внешний цикл

На внешнем validation:

- только оценка уже выбранной модели;
- никакого повторного выбора признаков.

Основные внешние метрики:

[
V_{pos},
V_{sign},
V_{margin},
V_{eq},
V_{var},
V_w.
]

Также сохранять:

- число выбранных признаков;
- набор выбранных признаков;
- частоту повторного выбора одного и того же subset;
- стабильность групповых средних eNRI.

## 11. Этап G. Longitudinal sensitivity

Из-за высокой индивидуальной вариабельности мышей отдельно анализировать внутримышиные изменения:

[
Delta x_i^{16}=x_i^{16}-x_i^0,
]

[
Delta x_i^{24}=x_i^{24}-x_i^0.
]

Этот анализ не заменяет основной constrained eNRI.

Он используется как дополнительная проверка: сильный кандидат желательно должен показывать согласованный longitudinal signal, а не только межгрупповое различие, вызванное несколькими отдельными мышами.

При необходимости дополнительно рассмотреть mixed-effects модели как sensitivity analysis.

## 12. Этап H. Переобучение сокращённого eNRI

После выбора окончательного subset:

1. оставить только выбранные признаки;
2. заново выполнить весь preprocessing;
3. заново вычислить baseline scaling;
4. заново вычислить (overline{x}_{PBS^0});
5. заново построить 12 состояний;
6. заново решить constrained QP;
7. получить новые веса.

Старые веса полной 30-признаковой модели не переносятся в reduced eNRI.

Сокращённая формула должна иметь вид

[
eNRI_{	ext{reduced}}
=
1+
sum_{jin S}
w_j^{	ext{reduced}}
(x_j-overline{x}_{PBS^0,j}),
]

где (S) — окончательный выбранный набор.

## 13. Этап I. Сравнение полного и сокращённого eNRI

Для reduced eNRI повторить полный Stage 8.

Сравнить с полной моделью:

- cosine similarity raw-scale slopes для общих признаков;
- sign agreement;
- индивидуальный Spearman eNRI;
- group-rank Spearman;
- group mean differences;
- positivity;
- equality errors;
- order errors;
- slack;
- complete-case sensitivity;
- (ho)-sensitivity;
- imputation sensitivity.

Отдельно проверить выполнение всех 10 биологических направленных условий.

## 14. Критерии для признания признака главным

Признак не признаётся главным только потому, что имеет большой (|w_j|).

Основные критерии:

1. высокая частота выбора в stability selection;
2. стабильный знак;
3. устойчивый raw-scale slope;
4. ухудшение validation-качества при его удалении;
5. отсутствие полной заменяемости соседним коррелированным признаком;
6. сохранение сигнала в longitudinal sensitivity;
7. повторный выбор во внешних nested-CV итерациях.

## 15. Методы, которые не использовать как основной способ отбора

Не использовать как основной критерий:

- top-(|w_j|) из одной full-data модели;
- stepwise regression;
- выбор по отдельным p-value;
- Random Forest feature importance;
- XGBoost feature importance;
- SHAP;
- PCA как финальный feature selector;
- чистый LASSO без (L_2)-части при сильной корреляции признаков.

Эти методы могут использоваться только как дополнительный exploratory/sensitivity анализ, если понадобится.

## 17. Текущее решение

До начала feature selection не объявлять набор главных признаков по текущим коэффициентам.

Текущие веса используются только как отправная точка для формирования кандидатов и проверки устойчивости.

Рабочая цель следующего этапа:

> Найти минимальный набор признаков, который устойчиво выбирается при изменении состава мышей и сохраняет out-of-sample выполнение биологических ограничений и качество полного eNRI.
