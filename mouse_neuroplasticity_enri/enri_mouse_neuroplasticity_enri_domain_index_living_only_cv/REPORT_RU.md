# Пересчёт eNRI: смерти не получают нули

**Смерть не имеет численного eNRI (NaN).** Ни один умерший не участвует
в расчёте групповых средних, дисперсии, ограничений QP или проверке индекса.

## Обработка

54 мыши; 140 исходных живых состояний, 22 состояния после смерти;
в основной очищенной версии 133 живых состояния после исключения
7 экстремальных поздних наблюдений.

Для 31-признакового исходного eNRI и моделей на 3/4 доменах
повторили preprocessing, baseline EFA, rank-domain scores и оптимизацию
в 9 разбиениях по мышам (36 train / 18 validation).
Учитывали только мышей train при обучении каждого этапа.
Все исходные параметры QP оставили одинаковыми: 0.1;
шесть мягких временных ограничений внутри групп.
Никаких запрограммированных преимуществ run/MCC над LPS.

### Основные показатели CV (очищенная выборка)

| Показатель (меньше лучше) | 31 признак | 3 домена | 4 домена |
|---|---:|---:|---:|
| Доля нарушений положительности | 0 | 0 | 0 |
| V_sign | 0.0185 | 0.2037 | 0.1852 |
| V_margin | 0.02310 | 0.04773 | 0.04151 |
| V_eq | 0.00396 | 0.01196 | 0.01101 |

Все значения определены только по живым на проверочных фолдах.
Исходная модель на 31 признаке лучше соблюдает заданные критерии,
но это не доказывает лучшей биологической валидности.

### Сходство индексов только у живых

Средняя корреляция новых индексов с исходным на validation:
- 3 домена: **0.506** (очищенные данные), **0.419** (все данные).
- 4 домена: **0.532** (очищенные данные), **0.459** (все данные).

**Негативный контроль:** если всем живым присвоить 1, V_sign=0,
V_margin=0.1. Сам показатель V_sign не свидетельствует о том,
что индекс измеряет функцию/нейропластичность.

### Весовая модель: 4 домена, очищенные данные

D1 +0.09974; D2 -0.07579; D3 -0.01859; D4 +0.00555.
Отрицательные веса обучения требуют уточнения направления
исходных Learning-показателей до биологической интерпретации.

## Что ещё нельзя утверждать

eNRI всё ещё не валидирован по независимой нейробиологической
мере нейропластичности. Сравнение групп при условии дожития
подвержено survivor bias. Нельзя делать вывод о причинном эффекте
run/MCC из данных, использованных для оптимизации индекса.
При CV EFA обучалась всего на ~36 мышах при 26 переменных.
Параметры QP зафиксированы из прежней работы, без нового nested tuning.
