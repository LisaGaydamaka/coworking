# Добавление массы тела к прогнозу D1–D3 · 24.10.2026

12 исходных задач (PBS 0→16 n=9, PBS 16→24 n=6, LPS 16→24 n=11, PBS 0→24 n=6) × D1–D3. Сопоставление строк доменных баллов и стандартизованного Weight по mouse_id, group, week, status (все 133 строки совпали). Источник веса: `enri_mouse_neuroplasticity_pca31_processed_drop_7_outlier_states/results/processed_matrix_31_living.csv`. Вес взят на **исходной** неделе, не на целевой.

Сравнение Ridge(alpha=1): только исходный домен против исходного домена + Weight. В каждом LOOCV-fold стандартизация каждого входа по обучающим мышам; одна мышь полностью исключена до fit. Дополнительные базовые прогнозы: без изменения и среднее будущего балла. Все 12 опубликованных обычных Ridge MAE воспроизведены с допуском <3e-6.

**Результат:** Ridge + Weight лучше Ridge в 3/12 задачах, лучше обеих простых альтернатив в 3/12, лучшая из четырёх в 2/12. Средняя MAE Ridge 0,817478 → 0,977812 после добавления Weight (**ухудшение на 19,6%**). Поэтому общего улучшения не получено.

**Ограничения:** Weight уже входил в исходную 31-признаковую обработанную матрицу и мог участвовать в построении факторных баллов. Стандартизованный Weight из источника, не килограммы/граммы; upstream импутация и EFA выполнялись до LOOCV. Это downstream regression-only LOOCV, а не полная независимая валидация. n=6–11, только выжившие пары. Не выбирать отдельные выигрышные задачи как подтверждение эффекта.

**Воспроизводимость:** `bash run.sh`. Итоги: `results/model_metrics.csv`, `leave_one_mouse_out_predictions.csv`, `SUMMARY.json`, `REPORT.md`. Исходные предыдущие проекты не изменяются.
