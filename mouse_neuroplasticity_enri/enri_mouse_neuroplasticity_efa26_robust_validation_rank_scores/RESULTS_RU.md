# Результаты проверки доменов: 26 признаков

Исходные данные: 54 мыши на week 0, из них 52 наблюдения без импутации.
Проекции: 133 очищенных мышь-неделя, альтернативно 140 исходных живых состояний.

Исключили пять избыточных признаков из 31: Learning_T1sum,
Learning_T2sum, Learning_T3sum, Average_speed_NOR1, Average_speed_NOR2.
Последние два почти полностью повторяли соответствующую дистанцию NOR
(Spearman 0.99825 и 0.99779).

Это не доказательство ошибки измерения; файлы источника не менялись.

При возвращении семи поздних состояний в анализ чувствительности,
например, PBS week24 D1 меняется -1.473 -> -0.995,
D2 +1.023 -> +0.489.

## Заключение

Основная рабочая модель — три домена на 26 признаках,
четырёхфакторная — обязательная проверка чувствительности.
Число факторов пока не является окончательно установленным.
Динамика доменов описательная, требуется longitudinal-моделирование
с учётом повторных измерений, пропусков и выживания.

Остаётся ограничение исходного preprocessing: импутация обучалась
на данных всех недель. Для строго проспективной оценки нужно
отдельно обучать preprocessing только на baseline.
