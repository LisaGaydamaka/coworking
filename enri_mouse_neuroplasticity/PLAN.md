# План решения задачи построения eNRI

## 1. Цель

Требуется по экспериментальным данным найти вектор весов

\[
\mathbf w=(w_1,\ldots,w_{35})^{\mathsf T},
\]

задающий экспериментальный индекс нейропластичности для живого состояния:

\[
eNRI(\mathbf x)
=
1+
\mathbf w^{\mathsf T}
\left(
\mathbf x-\overline{\mathbf x}_{PBS^{0}}
\right),
\]

где \(\mathbf x\) — стандартизованный вектор из 35 функциональных признаков. Нормировка фиксируется условием

\[
\overline{eNRI}_{PBS^{0}}=1,
\]

а смерть задаётся отдельно:

\[
eNRI(death)=0.
\]

Группа животного не является признаком eNRI и используется только для формирования ограничений задачи оптимизации.

## 2. Зафиксированная математическая постановка

### 2.1. Признаки

Используются 35 функциональных признаков, сопоставимых на 0-й, 16-й и 24-й неделях:

- OFT — 5 признаков;
- NOR1 — 8 признаков;
- NOR2 — 9 признаков;
- Rotarod learning — 9 признаков;
- Rotarod endurance — 1 признак;
- rearing — 2 признака;
- weight — 1 признак.

Производные индексы, молекулярные показатели, идентификатор животного, принадлежность к группе, Grip и неоднозначные Y-maze-поля в основной вектор признаков не включаются.

### 2.2. Исходные и стандартизованные значения

Исходный вектор измерений обозначается через

\[
\mathbf r=(r_1,\ldots,r_{35})^{\mathsf T}.
\]

Для каждого признака вычисляются параметры стандартизации \(m_j\) и \(s_j\), после чего

\[
x_j=\frac{r_j-m_j}{s_j}.
\]

Одни и те же параметры стандартизации применяются ко всем временным точкам. При кросс-валидации \(m_j\) и \(s_j\) вычисляются только по обучающей части выборки.

### 2.3. Равенства, связанные с рандомизацией

Зафиксировано множество

\[
\mathcal E=
\{
(PBS^{0},LPS^{0}),
(LPS^{16},run^{16}),
(LPS^{16},MCC^{16})
\}.
\]

Для пар \((A,B)\in\mathcal E\) средние значения eNRI должны быть близки.

### 2.4. Ограничения порядка

Межгрупповые сравнения:

\[
\mathcal O_1=
\{
(PBS^{16},LPS^{16}),
(PBS^{24},LPS^{24}),
(run^{24},LPS^{24}),
(MCC^{24},LPS^{24})
\}.
\]

Сравнения между 0-й и 16-й неделями:

\[
\mathcal O_2=
\{
(PBS^{0},PBS^{16}),
(LPS^{0},LPS^{16}),
(run^{0},run^{16}),
(MCC^{0},MCC^{16})
\}.
\]

Сравнения между 16-й и 24-й неделями:

\[
\mathcal O_3=
\{
(PBS^{16},PBS^{24}),
(LPS^{16},LPS^{24})
\}.
\]

Итоговое множество:

\[
\mathcal O=\mathcal O_1\cup\mathcal O_2\cup\mathcal O_3.
\]

Для ветвей run и MCC знак изменения между 16-й и 24-й неделями заранее не задаётся.

Минимальный требуемый разрыв фиксируется:

\[
\rho=1.
\]

Для каждой пары \((A,B)\in\mathcal O\) вводится переменная послабления \(\eta_{AB}\ge0\).

## 3. Подготовка данных

1. Загрузить исходный Excel-файл.
2. Выделить идентификатор животного, временную точку, экспериментальную ветвь и 35 фиксированных признаков.
3. Проверить типы данных и преобразовать числовые строки в числовой формат.
4. Проверить уникальность животных и соответствие ветвей экспериментальному дизайну.
5. Не использовать принадлежность к группе как компоненту \(\mathbf x\).
6. Не трактовать смерть как вектор с пропущенными признаками: \(eNRI(death)=0\) задаётся отдельно.
7. Для основной оптимизации использовать только наблюдаемые живые состояния, для которых сформирован полный 35-мерный вектор. Изолированные пропуски у живых животных документировать отдельно; не применять автоматическое глобальное заполнение медианой.
8. Сохранить подготовленную таблицу в длинном формате: одна строка — одно наблюдаемое состояние животного в конкретную неделю.

## 4. Стандартизация

Для каждого обучающего разбиения:

1. По обучающим наблюдениям вычислить \(m_j\) и \(s_j\), \(j=1,\ldots,35\).
2. Получить стандартизованные признаки
   \[
   x_j=(r_j-m_j)/s_j.
   \]
3. Те же \(m_j\) и \(s_j\) применить к проверочным данным.
4. Не выполнять отдельную стандартизацию для разных недель или групп.

## 5. Формирование экспериментальных состояний

Для каждого наблюдения сформировать принадлежность к одному из используемых состояний:

\[
PBS^{0},\ LPS^{0},\ run^{0},\ MCC^{0},
\]

\[
PBS^{16},\ LPS^{16},\ run^{16},\ MCC^{16},
\]

\[
PBS^{24},\ LPS^{24},\ run^{24},\ MCC^{24}.
\]

Обозначения \(run^{0}\), \(MCC^{0}\), \(run^{16}\), \(MCC^{16}\) относятся к тем животным исходной LPS-группы, которые после обследования 16-й недели были случайно распределены в соответствующие ветви.

## 6. Вычисление статистик состояний

Для каждого используемого состояния \(A\) вычислить средний вектор

\[
\overline{\mathbf x}_A
=
\frac{1}{|A|}
\sum_{\mathbf x\in A}\mathbf x
\]

и ковариационную матрицу

\[
\mathbf S_A
=
\frac{1}{|A|-1}
\sum_{\mathbf x\in A}
(\mathbf x-\overline{\mathbf x}_A)
(\mathbf x-\overline{\mathbf x}_A)^{\mathsf T}.
\]

Для каждой пары \((A,B)\in\mathcal E\cup\mathcal O\) вычислить

\[
\mathbf d_{AB}
=
\overline{\mathbf x}_A-
\overline{\mathbf x}_B.
\]

## 7. Формирование квадратичной задачи

Для фиксированных гиперпараметров \(\beta>0\), \(\lambda>0\) и \(C>0\) построить матрицу

\[
\mathbf Q=
\sum_{A\in\mathcal G}\mathbf S_A
+
\beta
\sum_{(A,B)\in\mathcal E}
\mathbf d_{AB}\mathbf d_{AB}^{\mathsf T}
+
\lambda\mathbf I.
\]

Задача принимает компактный вид

\[
\min_{\mathbf w,\boldsymbol\eta}
\left[
\mathbf w^{\mathsf T}\mathbf Q\mathbf w
+
C\sum_{(A,B)\in\mathcal O}\eta_{AB}
\right]
\]

при ограничениях

\[
\mathbf w^{\mathsf T}\mathbf d_{AB}
\ge
1-\eta_{AB},
\qquad
(A,B)\in\mathcal O,
\]

\[
\eta_{AB}\ge0,
\qquad
(A,B)\in\mathcal O,
\]

а также при условии положительности eNRI для каждого наблюдаемого живого состояния:

\[
1+
\mathbf w^{\mathsf T}
\left(
\mathbf x_i-
\overline{\mathbf x}_{PBS^{0}}
\right)
\ge\varepsilon,
\]

где \(\varepsilon>0\) — фиксированное малое число.

При \(\lambda>0\) матрица \(\mathbf Q\) положительно определена, поэтому задача является выпуклой квадратичной задачей программирования.

## 8. Численное решение QP

1. Пронумеровать пары из \(\mathcal O\): \((A_k,B_k)\), \(k=1,\ldots,K\).
2. Объединить неизвестные в вектор
   \[
   \mathbf y=
   \begin{pmatrix}
   \mathbf w\\
   \boldsymbol\eta
   \end{pmatrix}.
   \]
3. Сформировать стандартную QP-форму
   \[
   \min_{\mathbf y}
   \left(
   \frac12\mathbf y^{\mathsf T}\mathbf H\mathbf y+
   \mathbf f^{\mathsf T}\mathbf y
   \right)
   \]
   при линейных ограничениях \(\mathbf A\mathbf y\le\mathbf b\).
4. Использовать CVXPY с QP-решателем, например OSQP; при необходимости проверить решение вторым выпуклым решателем.
5. Для каждого запуска сохранять статус решателя, значение целевой функции, \(\widehat{\mathbf w}\), \(\widehat{\boldsymbol\eta}\) и остатки всех ограничений.

## 9. Подбор гиперпараметров

Подбираются

\[
\beta,\qquad\lambda,\qquad C.
\]

Начальная сетка:

\[
\{10^{-3},10^{-2},10^{-1},1,10,10^2,10^3\}.
\]

Для каждой тройки \((\beta,\lambda,C)\):

1. Разбить данные на обучающую и проверочную части по животным.
2. Все временные точки одной мыши должны находиться только в одной части разбиения.
3. На обучающей части выполнить стандартизацию и построить QP.
4. Найти \(\widehat{\mathbf w}\).
5. Применить этот же вектор весов к проверочным животным.
6. На проверочной части вычислить:
   - число и величину нарушений отношений из \(\mathcal O\);
   - остатки равенств для пар из \(\mathcal E\);
   - наличие нарушений положительности eNRI;
   - внутригрупповой разброс eNRI;
   - стабильность знаков и величин компонент \(\mathbf w\) между разбиениями.
7. Отбирать параметры по устойчивому выполнению ограничений на независимых мышах, а не по качеству на обучающей выборке.

При малом размере выборки предпочтительно использовать повторную кросс-валидацию или leave-group-out схему по животным, а не одно случайное разбиение.

## 10. Финальная оценка весов

После выбора \(\beta\), \(\lambda\) и \(C\):

1. Повторно вычислить параметры стандартизации на всей доступной выборке живых состояний.
2. Построить \(\overline{\mathbf x}_A\), \(\mathbf S_A\), \(\mathbf d_{AB}\) и \(\mathbf Q\).
3. Решить QP на всей выборке.
4. Получить окончательный вектор
   \[
   \widehat{\mathbf w}
   =
   (\widehat w_1,\ldots,\widehat w_{35})^{\mathsf T}.
   \]
5. Рассчитать
   \[
   eNRI(\mathbf x_i)
   =
   1+
   \widehat{\mathbf w}^{\mathsf T}
   \left(
   \mathbf x_i-
   \overline{\mathbf x}_{PBS^{0}}
   \right)
   \]
   для каждого наблюдаемого живого состояния.

## 11. Диагностика решения

После получения финального решения сформировать:

1. таблицу 35 весов \(\widehat w_j\);
2. таблицу eNRI для всех наблюдаемых состояний;
3. средние и дисперсии eNRI по экспериментальным состояниям;
4. таблицу всех сравнений из \(\mathcal O\):
   \[
   \overline{eNRI}_A-\overline{eNRI}_B;
   \]
5. значения всех \(\widehat\eta_{AB}\);
6. остатки условий из \(\mathcal E\);
7. минимальное значение eNRI среди живых наблюдений;
8. список наиболее крупных переменных послабления \(\widehat\eta_{AB}\), поскольку они показывают, какие априорные отношения хуже всего поддерживаются данными.

## 12. Оценка устойчивости

Выполнить bootstrap по животным:

1. случайно выбирать животных с возвращением;
2. включать в bootstrap-выборку все временные точки выбранного животного;
3. заново выполнять стандартизацию и решение QP;
4. сохранять \(\widehat{\mathbf w}\), средние eNRI и \(\widehat{\boldsymbol\eta}\);
5. по распределениям оценить устойчивость весов, их знаков и экспериментальных сравнений.

Особое внимание уделить признакам, для которых вес часто меняет знак или имеет большой разброс.

После реализации сохранить внутри этой папки:

- подготовленные данные для моделирования;
- параметры стандартизации;
- финальные 35 весов;
- рассчитанные значения eNRI;
- отчёт по ограничениям \(\mathcal E\) и \(\mathcal O\);
- результаты подбора \(\beta\), \(\lambda\), \(C\);
- bootstrap-оценки устойчивости;
- диагностические таблицы и графики;

Если проект становится запускаемым через общий workflow репозитория, в папке должны быть добавлены `run.sh` и `.run` в соответствии с правилами корневого README.
